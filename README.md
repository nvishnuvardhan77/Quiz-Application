# Quiz Application

A simple interactive quiz application built using HTML, CSS, and JavaScript.

## Features
- Start the quiz
- Answer multiple-choice questions
- Navigate to the next question
- Restart the quiz

## Technologies Used
- HTML
- CSS
- JavaScript
